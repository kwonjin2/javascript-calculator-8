# javascript-calculator-precourse

## 구현할 기능 목록

- 문자열 입력받기
  - 사용자에게 문자열을 입력받기 (구분자와 양수로 구성된 문자열)
- 커스텀 구분자 처리하는 함수 만들기
  - 사용자가 입력한 문자열에서 커스텀 구분자를 확인
- 문자열 처리하는 함수 만들기
  - 문자열을 기본 구분자를 기준으로 분리해서 추출
  - 문자열을 커스텀 구분자를 기준으로 분리해서 추출
- 에러 처리하기
  - 빈 값이 들어올 경우
  - 잘못된 커스텀 구분자 사용 처리
  - 양수가 아닌 음수로 구성된 문자열의 경우 (이 때는 커스텀 구분자가 '-' 가 아닌경우)

### 기능을 정리하긴 했지만..

- 어디서 에러를 처리해야할 지 아직은 잘 모르겠다
  - 사용자에게 입력을 받자마자 에러를 처리하는 경우
  - 기본 구분자 기준으로 분리할 때 에러를 처리하는 경우
  - 커스텀 구분자를 기준으로 분리할 때 에러를 처리하는 경우

- 우선 기능 구현을 하면서 수정해나가야할 것 같다.
