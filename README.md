# javascript-calculator-precourse

## 구현할 기능 목록

- 문자열 입력받기
  - 사용자에게 문자열을 입력받기 (구분자와 양수로 구성된 문자열)
- 문자열 처리하는 메서드 만들기
  - 커스텀 구분자를 확인하는 메서드 구현
  - 구분자를 제거하는 메서드 구현
  - 문자형 -> 숫자형으로 변환하는 메서드 구현
  - 숫자형 배열을 받아 합산하는 메서드 구현
- 예외 처리하기
  - 잘못된 커스텀 구분자 사용 처리
    - 커스텀 구분자가 비어있는 경우 -> 에러
    - 커스텀 구분자가 숫자인 경우 -> 에러
    - 커스텀 구분자가 특수 문자인 경우(정규 표현식에서 오류의 원인) -> 동작하게 해야할 것 같다.
    - -> checkCustomDelimiter에서 처리
  - 잘못된 입력을 하는 경우
    - 양수가 아닌 음수로 구성된 문자열의 경우 -> 에러
    - //-\n1;2;3 과 같이 커스텀 구분자를 지정했지만 커스텀 구분자를 사용하지 않은 ;를 사용하는 경우 -> 에러
    - 1,2;3//;\n 과 같이 순서를 잘못 입력할 경우 -> 에러
    - 입력 문자열에 구분자만 있는 경우 (,: or //;\n;;;) -> 에러
    - 빈 값이 들어올 경우 -> 0 반환
    - -> calculateSumFromString에서 처리
